- 주어진 공항 수는 3개 이상 10,000개 이하입니다.
- tickets의 각 행 [a, b]는 a 공항에서 b 공항으로 가는 항공권이 있다는 의미입니다.
- 주어진 항공권은 모두 사용해야 합니다.
- 만일 가능한 경로가 2개 이상일 경우 알파벳 순서가 앞서는 경로를 return 합니다.
- 모든 도시를 방문할 수 없는 경우는 주어지지 않습니다.

**Checkpoint**

- 백트래킹(Backtracking)
    - 모든 가능한 경우의 수를 탐색하되, 해가 될 가능성이 없는 경로는 도중에 포기하고 되돌아가서(Backtrack) 다음 경로를 탐색하는 알고리즘
    ```
    def backtracking(node):
        # 1. 유망성 검사: 현재 노드가 조건에 맞지 않으면 즉시 종료 (가지치기)
        if not is_promising(node):
            return
            
        # 2. 정답 발견: 원하는 조건을 만족하면 결과 처리 후 종료
        if is_complete(node):
            print_solution()
            return
            
        # 3. 자식 노드 탐색: 다음 단계의 가능한 모든 선택지 진행
        for child in get_children(node):
            make_choice(child)       # 선택 반영
            backtracking(child)      # 재귀 호출
            undo_choice(child)       # 되돌리기 (상태 복원)
    ```
    | 구분 | DFS (깊이 우선 탐색) | 백트래킹 (Backtracking) |
    | --- | --- | --- |
    | 목적 | 그래프나 트리의 모든 노드를 방문하는 것 | 조건에 맞는 최적의 해를 효율적으로 찾는 것 |
    | 특징 | 정답이 아닌 경로도 끝까지 탐색함 | 유망하지 않으면 도중에 탐색을 중단하고 돌아옴 |
    | 효율성 | 경우에 따라 무한 루프나 메모리 낭비 발생 | 가지치기를 통해 탐색 횟수를 획기적으로 줄임 |
