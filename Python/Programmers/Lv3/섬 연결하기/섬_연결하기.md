n개의 섬 사이에 다리를 건설하는 비용(costs)이 주어질 때, 최소의 비용으로 모든 섬이 서로 통행 가능하도록 만들 때 필요한 최소 비용을 return 하도록 solution을 완성하세요.

다리를 여러 번 건너더라도, 도달할 수만 있으면 통행 가능하다고 봅니다. 예를 들어 A 섬과 B 섬 사이에 다리가 있고, B 섬과 C 섬 사이에 다리가 있으면 A 섬과 C 섬은 서로 통행 가능합니다.

---

- 섬의 개수 n은 1 이상 100 이하입니다.
- costs의 길이는 `((n-1) * n) / 2`이하입니다.
- 임의의 i에 대해, costs[i][0] 와 costs[i] [1]에는 다리가 연결되는 두 섬의 번호가 들어있고, costs[i] [2]에는 이 두 섬을 연결하는 다리를 건설할 때 드는 비용입니다.
- 같은 연결은 두 번 주어지지 않습니다. 또한 순서가 바뀌더라도 같은 연결로 봅니다. 즉 0과 1 사이를 연결하는 비용이 주어졌을 때, 1과 0의 비용이 주어지지 않습니다.
- 모든 섬 사이의 다리 건설 비용이 주어지지 않습니다. 이 경우, 두 섬 사이의 건설이 불가능한 것으로 봅니다.
- 연결할 수 없는 섬은 주어지지 않습니다.

**Checkpoint**

- 최소 신장 트리 (MST; Minimum Spanning Tree)
    - 그래프의 모든 정점을 연결하면서 사이클이 없는 그래프인 신장 트리(Spanning Tree) 중 간선 가중치의 합이 가장 작은 트리
- 크루스칼(Kruskal) 알고리즘
    - 그래프의 모든 정점을 최소 비용으로 연결하는 알고리즘
    1. 모든 간선을 비용이 작은 순서대로 정렬
    2. 비용이 작은 간선부터 선택 (간선을 추가했을 때 사이클이 생긴다면 선택 X)
- Union-Find (서로소 집합)
    - 여러 원소가 어떤 집합에 속하는지 관리하는 자료구조
    - 두 원소가 같은 집합에 속하는지 빠르게 확인하고, 서로 다른 두 집합을 하나로 합칠 때 사용
        - Kruskal 알고리즘에서 두 정점이 이미 연결되어 있는지 효율적으로 확인하는 방법
    - `find(x)` 연산
        - `x`가 속한 집합의 대표 원소(루트)를 찾음
        ```python
        def find(x):
            # 자기 자신이 부모인지 확인
            if parent[x] != x:
                # 재귀적으로 루트 탐색
                parent[x] = find(parent[x])
        
            return parent[x]
        ```
    - `union(a, b)` 연산
        - a와 b가 속한 두 집합을 하나로 합침
        ```python
        def union(a, b):
            # 각 원소의 루트 찾기
            root_a = find(a)
            root_b = find(b)
        
            # 이미 같은 집합인지 확인
            if root_a == root_b:
                return False
        
            # 서로 다른 집합이라면 합치기
            parent[root_b] = root_a
        
            return True
        ```
    - `parent` 배열
        - `parent[x]`는 `x`의 부모 노드를 의미
        - 초기 상태에서는 각 원소가 자기 자신을 부모로 가짐
        - 부모가 자기 자신인 노드는 해당 집합의 대표 원소
